# Ishaan Interiors static website

## Deploy to Hostinger

1. Upload the contents of `ishaan-deploy.zip` into the domain's `public_html`
   directory and extract the archive there.
2. Confirm `index.html` is directly inside `public_html` (not inside another
   folder).
3. Visit the domain and test the navigation, product pages, contact form, and
   images.

The site is static HTML, CSS, and JavaScript. Keep the HTML pages, shared
styles/scripts, and `ishaan-logo.jpg` together in the same directory. Product
selection is stored in the visitor's browser; contact enquiries open WhatsApp.
The newsletter form is a front-end interaction and does not subscribe to an
email service. Product imagery and web fonts load from external providers, so
visitors need an internet connection to see those resources.

## Included site pages

- `index.html` — home
- `about.html`
- `product.html` — product directory
- `panels n louvers.html`
- `sofit-panels.html`
- `home-decorative.html`
- `specialty sheets.html`
- `french moulding.html`
- `false ceiling.html`
- `exterior products.html`
- `PU products.html`
- `gallery.html`
- `contact.html`

The shared navigation and footer are generated by `site-shell.js`. Keep
`nav.css`, `footer.css`, `footer.js`, `site-shell.js`, and `ishaan-logo.jpg`
beside the pages when deploying.
